## How to Take Screenshots

1. Run your app: `http://localhost:8080`
2. Take screenshots of:
   - Login/register page
   - Empty dashboard after login
   - Dashboard with contacts in sidebar
   - Active conversation with messages
   - Add contact feature
   - Timer settings dropdown
3. Name them according to the filenames referenced in README.md
4. Update the README.md file paths if needed

## Tips for Good Screenshots

- Use a clean browser window (no bookmarks bar)
- Consider using incognito mode for clean interface
- Take screenshots at common screen resolution (1920x1080)
- Show realistic data (don't use "test" or "asdf" - use real-looking usernames)
- Capture the dark theme in good lighting
- Show the live countdown timers if possible
